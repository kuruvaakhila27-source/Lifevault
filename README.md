# 🔐 LifeVault

### Your Personal Digital Vault

LifeVault is an AI-powered document management app that helps users upload, organize, understand and search important documents.

## ✨ Features

- 📤 PDF document upload
- 📄 Automatic text extraction
- 🧠 Document information extraction
- 🤖 AI document analysis using Ollama + Llama 3.2
- ⏰ Smart warranty and expiry tracking
- 🔔 Expiry alerts
- 🗂️ Automatic document categories
- 🔍 Document search
- 🤖 Ask LifeVault AI
- 🗑️ Document management and deletion
- 📊 Smart dashboard

## 🛠️ Technologies

- Python
- Streamlit
- PyMuPDF
- SQLite
- Ollama
- Llama 3.2
